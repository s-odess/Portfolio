Model-in-the-Loop Production Workflow

Citizen · ChatGPT Enterprise

I designed, built, and ran a model-in-the-loop workflow on ChatGPT Enterprise for California, Citizen's largest market, with no engineering or product support. Users submitted video of emergencies that arrived without context, and the workflow translated first-responder jargon into clear narrative around that video. The custom editorial rulebook I wrote for it required source attribution, flagging of conflicting reports, and a human review checkpoint before publishing.

The workflow ran in production for more than two years, cut manual processing by 10 minutes per push series, and drove an estimated 1 million plus additional weekly notifications (my own estimate from user volume and escalation rates).

Output Quality Evaluation Framework

Citizen · OpenAI Codex, macOS Shortcuts, Bash

Citizen's operations team began by listening to first-responder radio clips and writing notification copy by hand. Over time, an automated authoring model took over the first draft, and the team reviewed each model-authored notification against two standards: empirical accuracy against the clip itself, and adherence to Citizen's editorial, style, privacy, and safety guidelines. That authoring model was a separate system from the ChatGPT Enterprise workflow above.

I built an independent evaluation framework with OpenAI Codex, macOS Shortcuts, and Bash and audited more than 1,000 live outputs from that model against service-level standards for accuracy, privacy, and editorial quality. I defined concrete failure categories, tracked quality in a time-series graph, and surfaced a 12% peak error rate. QA scores rose after a leadership-backed recalibration.

01Current state
Citizen closely tracked the operations team's error rate and kept no separate error rate for the automated authoring model whose outputs the team reviewed.
02Future state
The team, its manager, and leadership know the model's own error rate.
03Implementation
I captured the 1,000+ outputs as screenshots in real time with hotkeys I built in macOS Shortcuts, alongside my regular output and service-level obligations, and audited each one against the standard.
04Measurement
Bash scripts generated a time-series graph of quality in half-hour increments, which surfaced the 12% peak.
66% hour reduction absorbed 3× regional output 4× retention built with an engineer

CHP Dispatch Intelligence Pipeline

Independent · Python, Playwright, Gemini API, GitHub REST API

I built this independent Python pipeline to automate a workflow I ran by hand for two years at Citizen. Playwright extracts live California Highway Patrol incident data from a legacy ASP.NET dispatch dashboard and opens each incident's detail page for the location and coordinates. The pipeline sends the records to the Gemini API, where a constrained prompt turns dispatch shorthand into plain-English summaries. The code retries on rate-limit and server errors, caps each run to protect the API quota, and publishes structured JSON to a public GitHub repository through the GitHub REST API.

I build through language-model-assisted development (Cursor, OpenAI Codex, Claude Code, Claude, Gemini): I specify the task, review and test the model's work, and iterate.

What I learned: the back end came together quickly, while the map front end I tried to build on top of it never worked, so I kept the pipeline and its JSON output. An earlier version captured the full dispatch log from each incident's detail page, and restoring that depth is my next step.

The pipeline runs from the command line, and the repository includes a GitHub Actions workflow. Source code and README.

Creators Program Launch

Citizen · Volunteered, outside my formal job description

Citizen bought and aggressively solicited user video, and staff imported each clip by hand, downloading the video file and uploading it into the proprietary operating system. I volunteered to launch the Creators Program for the operations team on my own initiative, outside my job description, and kept meeting my service-level commitments throughout. The program later became tied to Citizen's partnership with Axon.

For several months I served as the program's main contact within the operations team and introduced the team to it. I wrote most of the program guide with the head of marketing and the head of the consumer subscription team. The guide set standards for which user-submitted video belonged in the app and which did not, including content too sensitive to publish regardless of its viral potential.

I trained freelance video creators to tailor their footage to Citizen's editorial guidelines, trained the people on the creators team, and worked on launch procedures that readied the team for video-first. Because submitted video arrived without editorial context, I built the model-in-the-loop workflow described above to write the narrative around it.

While we worked together on the launch, I trained the head of marketing hands-on in Tableau for several months, also outside my job description, so that she could pull the engagement and growth metrics her role required.
